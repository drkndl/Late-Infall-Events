1. Load .vtk file
2. Click on gasdens600.vtk in the pipeline tree on the left
3. Click Apply

Changing coordinates
--------------------
1. Click on Filters > Alphabetical > Clean to grid
2. Click Apply
3. Click on Calculator > check Coordinate Results 
4. Add following formula in the empty box: coordsX*sin(coordsY)*cos(coordsZ)iHat + coordsX*sin(coordsY)*sin(coordsZ)jHat + coordsX*cos(coordsY)*kHat
5. Click on Save Expression below the formula box
6. Click Apply 

Loading isosurfaces
-------------------
1. Click on Calculator in the pipeline tree on the left so that the isosurfaces are under calculator pipeline.
2. Click on "Generate isolines or isosurfaces" in the toolbar.
3. In 'Isosurfaces' in the Properties dialog box, click on the Red X in the Value Range where a single data point is listed.
4. Click on empty square above the Red X to add new range of values for isosurfaces.
5. Add range in "Generate number series" dialog box that opens up.
6. Choose "Logarithmic" for Type if applicable.
7. Choose appropriate number of samples. Higher the number, greater is the RAM load.
8. Scroll down to "Styling" to change opacity as necessary.
9. Scroll down to "Coloring" to change colormap as necessary. (see below)

Changing data threshold
-----------------------
1. Click on Calculator in the pipeline tree on the left so that the thresholds are under calculator pipeline.
2. Click on "Extract cells that satisfy a certain threshold criterion" in the toolbar.
3. Change Threshold Method as necessary. Note that "Above upper threshold" actually requires us to provide a lower threshold from which the datapoints are filtered.
4. Change Threshold values as necessary.
5. Click on Apply.

Switch between views
--------------------
1. Click on eye in the pipeline tree to toggle a specific 'filter' on or off

Change colormap Properties
--------------------------
1. Ensure you have chosen the right filter in the pipeline tree to which you want to change the colormap properties.
2. Click on Edit Colormap on the toolbar.
3. Click on "Set a colormap from default presets" to change the type of colormap. Check "Use log scale when mapping data to colours".
4. Click on "Rescale to custom data range" on the toolbar to add a custom range for the colormap in the dialog box that opens.
5. Click on "Toggle colorbar visibility" to toggle colorbar on/off.

Creating animations
-------------------
1. Ensure all .vtk files are saved in the same folder and named in an iterable way (gasdens0.vtk, gasdens1.vtk ....)
2. Open ParaView and select the header of the drop-down listing all the files that should appear if all files are in the same folder and named correctly. 
3. If there are problems loading the .vtk file, open using the "Legacy VTK Reader" in the "Open With" option in the dialog box.
4. Apply usual filters and isosurfaces to the loaded vtk file. 
5. Once you are happy with the state loaded, press the Play button in the toolbar. Everything is working correctly if the "Time: " button in the toolbar says "max is 450" where 450 in this example is the final iteration number.
6. All the iterations will render to the same loaded state and you should see it update. Each iteration takes around 2 seconds.
7. Go to File > Save Animation to save into a .avi movie. Give the file a name and choose file type as .avi. The animation takes time to complete.

Adding simulation time to animation panels
------------------------------------------
1. To annotate the simulation time onto each iteration loaded state, go to Filters -> Alphabetical -> Annotate Time Filter and click Apply.
2. To convert iteration time to simulation time, change Format in Properties to "Time: {time:.2f} kyr" and change Scale to 0.1186 where Scale = it * ninterm * dt / stoky based on my FARGO3D simulation parameters where it = iteration number from 0 to 450, dt = timestep = 1.87e7 seconds, ninterm = number of iterations between each output = 200, stoky = 3.156e10 to convert seconds to kilo years.

Adding title
------------
1. Go to Sources -> Annotation -> Text
2. Add the required text in the provided textbox (the default is just "text"). 
3. Adjust title orientation and size as necessary.

Adding scale
------------
1. On the RenderView window, just below 'Layout #1', there is a toggle interaction mode button set to '3D'. Change it to '2D' by just clicking on it. 
2. Go to Sources > Ruler
3. Add coordinates in Point1 and Point2 to add a ruler or a scale bar. Note that these coordinates have to be in whatever units the data is in. So cm in my case. So if I am viewing my disk on the X-Z plane and I want to draw a horizontal scale bar of 100 au on the bottom-left of my screen, I can use Point1: -3.5e15, 0, -2.7e15 and Point2: -4.996e15, 0, -2.7e15. Of course adjust values based on your requirement. 
4. How to know what my coordinate limits even are? In the Contour1 tab (or whatever the pipeline you are viewing is called), go from Properties to Information. There is a parameter called 'Bounds' in 'Data Statistics' where you can see the bounds of your simulation. So you can decide the scale and placement of the scale based on that.
5. Back to Ruler1 properties, you can change the number of ticks, axis colour, and axis line width.

Adding scale label
-----------------
1. This is a hacky way to add a label to your scale bar. Sources > Annotations > Text
2. Add the required text in the provided textbox for e.g. '100 au'.
3. Adjust the coordinates of the text until the scale label is aligned with the scale line. To do this, look at Use Coordinates which provides the x- and y- coordinates of the text in the window, with x=0 to x=1 going from left to right, and y=0 to y=1 going from bottom to top.
